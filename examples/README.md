# Example result sets

Synthetic, generated by a seeded script for the action smoke test and for trying
`probo report` and `probo compare` without Docker. Every record carries `"synthetic": true`.
They show the file shape only; the numbers mean nothing.

```bash
uv run probo report examples/baseline.jsonl
uv run probo compare examples/baseline.jsonl examples/with-skill.jsonl
```
